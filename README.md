# IoT-Based Intelligent Air Monitoring and Purification System

## Project Overview

This undergraduate research project focuses on the design and development of an IoT-based intelligent air monitoring and purification system to improve indoor air quality through real-time monitoring, automated purification and intelligent decision-making.

## Project Objectives

- Develop a real-time indoor air quality monitoring system.
- Integrate environmental sensors with an ESP32 microcontroller.
- Develop an intelligent and automated air purification mechanism.
- Implement a web-based dashboard for remote monitoring and system control.
- Investigate machine learning techniques for air quality prediction and purification optimisation.
- Evaluate system performance and commercial feasibility.

## Proposed Features

- Real-time air quality monitoring
- Particulate matter and gas monitoring
- Automated fan speed control
- Multi-stage air filtration
- IoT connectivity
- Interactive web dashboard
- Historical data visualisation
- Air quality notifications
- Machine learning-based intelligent control
